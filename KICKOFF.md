# Первый промпт для Claude Code

Перед промптом выполни в Claude Code `/effort max` и выбери модель через `/model`. Затем включи режим планирования клавишами Shift+Tab и вставь текст ниже.

```text
Прочитай CLAUDE.md и файлы в .claude/agents. Работаем в режиме планирования.
Задача: этапы 0 и 1 из CLAUDE.md. Создай SwiftUI-проект SpantherGaze (iOS 16 и новее, только iPhone, портрет) на ARKit face tracking.
1. Экран отладки: центры глазных яблок, поза головы, расстояние до лица, FPS и время обработки кадра.
2. Модуль GazeCore без зависимости от UI: lookAtPoint в мировых координатах, пересечение луча с плоскостью экрана, ridge-регрессия калибровки, фильтр One Euro, метрики точности.
3. Экран калибровки на 9 точек и экран проверки на 13 других точек: средняя ошибка и дрожание в pt, см и градусах.
4. Запись сырых данных сессии в CSV и экспорт через меню «Поделиться».
5. Модульные тесты GazeCore на синтетических данных.
Сначала покажи план: структура файлов, порядок работ, как проверишь каждый шаг и что тебе неясно.
После моего утверждения раздай работу субагентам arkit-gaze, calibration-math, game-ui и device-qa, собери проект и установи на подключённый iPhone через XcodeBuildMCP.
```

После прогона на телефоне экспортируй CSV с экрана проверки. Дальше отдай его Claude Code для разбора или пришли в чат, где составлялся план.
