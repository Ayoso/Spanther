# SPANTHER

Eye-controlled iPhone game for attention training (kids 6–10): look at a meteor and hold your gaze until it bursts; bigger meteors need a longer look.

- `SpantherGaze/` – the iOS app (SwiftUI, SpriteKit, ARKit). See its README for building with Xcode and SIDELOAD.md for installing without a Mac.
- `docs/` – balance and eye-tracking notes.
- `CLAUDE.md` – project rules and stages.
